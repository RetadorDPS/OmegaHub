    Conexión

    Estos datos están en tu navegador. La anon key es pública por diseño; lo que protege tus datos es el RLS de Supabase.

    Cómo conectar las manos (el ejecutor)
    1. Instala Firefox para Android y, dentro, la extensión Violentmonkey.
    2. Abre el fichero phone-agent.user.js y cópialo todo.
    3. En Violentmonkey crea un script nuevo y pega el contenido.
    4. Abre la consola del navegador en una pestaña con el script activo y escribe: window.phoneAgent.setup({supabaseUrl:"…", anonKey:"…", channel:"…"})
    5. Abre Google y Claude en otras pestañas. Verás la etiqueta 🤖 abajo a la izquierda.

    Alternativa sin consola: pega el mismo objeto dentro del script, en la llamada saveCfg del arranque.
