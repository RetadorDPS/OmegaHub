Cómo comprobarlo tú mismo

· Productos de una tienda: abre https://mitienda.com/products.json?limit=5 en el navegador. Verás exactamente el mismo JSON que lee el sistema.

· Términos del día: trends.google.com/trending?geo=ES. Los títulos coinciden con los guardados.

· Procedencia de cada cifra: en la ficha de cualquier producto, el sello de confianza indica la fuente, la fecha y si fue medida o estimada.
