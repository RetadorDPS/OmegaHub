Empezar en 30 segundos

Autentica con Authorization: Bearer o con X-API-Key.

curl "https://tudominio.com/api/v1/productos?categoria=Belleza&minScore=70" \
  -H "Authorization: Bearer thp_live_TU_CLAVE"
// JavaScript / TypeScript
const respuesta = await fetch("https://tudominio.com/api/v1/productos?orden=margen", {
  headers: { Authorization: "Bearer thp_live_TU_CLAVE" },
});
const { data, meta } = await respuesta.json();
Todas las respuestas incluyen data y meta. Los errores siguen el formato { error: { codigo, mensaje } }. La API admite CORS y expone X-RateLimit-* y X-Quota-*.
Descargar OpenAPI 3.1

Cuotas y buenas prácticas

Límites por clave, no por usuario: separa integraciones.

  • · Business: 60 peticiones/minuto · 5.000/día · 5 claves.
  • · Agency: 300 peticiones/minuto · 50.000/día · 20 claves.
  • · Respeta Retry-After cuando recibas un 429.
  • · Cachea las listas unos minutos: el catálogo se recalcula a diario.
  • · Usa porPagina ≤ 50 y guarda el cursor por página.
  • · Cada clave revocada deja de funcionar al instante.
La API es de solo lectura: no crea productos ni modifica seguimientos. Para eso están los endpoints internos del panel.
